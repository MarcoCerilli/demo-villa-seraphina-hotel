# Villa Seraphina Resort & SPA | Riviera Boutique Retreat

Piattaforma hospitality di lusso con booking engine interattivo, calcolo date check-in/out, collezione suite panoramiche e pacchetti benessere SPA.

## 🚀 Guida Rapida Deploy su Vercel

Questo progetto è un'applicazione React + Vite + Tailwind CSS autonoma e indipendente al 100%, pronta per essere caricata su una repository GitHub dedicata e pubblicata su Vercel.

### 1. Esegui in Locale
```bash
npm install
npm run dev
```

### 2. Build di Produzione
```bash
npm run build
```

### 3. Pubblicazione su GitHub & Vercel
1. Crea una nuova repository su GitHub: `https://github.com/new` (es. `villa-seraphina-hotel-demo`).
2. Inizializza Git e carica il codice:
```bash
git init
git add .
git commit -m "feat: initial commit for Villa Seraphina Resort & SPA | Riviera Boutique Retreat"
git branch -M main
git remote add origin https://github.com/TUO-USERNAME/villa-seraphina-hotel-demo.git
git push -u origin main
```
3. Vai su [Vercel](https://vercel.com/new), importa la repository e clicca **Deploy**.
